# Net Probability

Premier League 2026–27 shot-quality and expected-goals research. A non-commercial portfolio project with chronological model evaluation and an interactive dashboard.

## Status
Foundation in progress. No live deployment or model performance is claimed yet.

## Planned workflow
Pinned shot snapshot → validated features → match/date-separated training and evaluation → SQLite/JSON → static dashboard → GitHub Pages.

Source: [pl-catalogue](https://github.com/oladeeayo/pl-catalogue), underlying shot provider Understat. Attribution and upstream provider rights apply. See [data provenance](docs/DATA.md).

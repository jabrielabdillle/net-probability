# Data provenance and use

Compilation: https://github.com/oladeeayo/pl-catalogue
Pinned commit: `5a9d2391d8cf1879a54c8a67bc25039c454479f0`
Files: `data/2026-27/shots.csv`, `fixtures.csv`, `manifest.json`.
Manifest export timestamp: 2026-11-10T10:26:32 (source does not specify timezone).
Source describes shots as Understat data; normalized x/y in [0,1], attack toward x=1. Convert to an assumed 105×68m pitch; goal width 7.32m. These are modeling dimensions, not measured stadium dimensions.

The compilation README permits attributed personal projects, research and non-commercial dashboards. It prohibits selling, sublicensing or charging for the data. Upstream provider rights remain with providers. Link to pl-catalogue in the app and retain attribution in exports; no claim of affiliation or an official league feed. Do not apply the code license to source or derived data. Do not publish unrelated personal/profile data.

Coverage is a pinned partial-season snapshot, not a live or complete season feed. Validate actual match/date counts and join integrity. Display excluded penalties/own goals and missing-data findings. Player text is a source label rather than a verified cross-provider identity.
